Build Guide

Building the JV Feeder Generator in Power Apps

A phase-by-phase walkthrough for building the Canvas App mockup as a real app — SharePoint, two Office Scripts, two Power Automate flows, and the app's three screens. Written for someone who hasn't built in Power Apps or Office Scripts before. Check off phases in the sidebar as you go — your progress is saved in this browser.

What you're replacing
populate_jv_feeder.py — a script only one person could run.
Connectors used
SharePoint & Excel Online (Business) — both standard, no premium license required for the people who'll use the app.
Time estimate
A focused first pass: half a day for setup + scripts, half a day for the flows and app.

Before You Start

What you need in hand before opening Power Apps Studio.

1

Gather three files

  • The blank JVFeederTemplate.xlsx (just the header row, no data)
  • A sample extract file (.xlsx or .csv) to test with
  • The two Office Script files: ReadSourceRows.ts and PopulateFeederTemplate.ts
2

Confirm access

You'll need: a SharePoint site you can create document libraries in, Power Apps + Power Automate licensing (you've confirmed premium works for your org), and Excel Online access to that same SharePoint site.

Build one phase at a time
Each phase below is testable on its own before you move to the next — test the scripts in Excel before wiring them into a flow, test each flow in Power Automate's test panel before calling it from the app. Skipping ahead is where most of the debugging pain comes from.
1

Set Up SharePoint

A working area for the app's files. Everything here uses the standard SharePoint connector.

1

Create a document library

On the SharePoint site you'll use, create a new document library called JV Feeder Files.

2

Create three folders inside it

  • Templates — holds the blank feeder template, nobody else writes here
  • Uploads — temporary copies of what users upload
  • Outputs — generated feeders, ready for download
3

Upload the blank template

Put JVFeederTemplate.xlsx into the Templates folder. This exact file is copied fresh every time someone generates a feeder — it's never edited directly.

Financial data, temporary files
Uploads and Outputs will accumulate files with real GL data. Once the app works, come back and add a short-retention policy — either a scheduled flow that deletes anything older than a few days, or a SharePoint retention policy on those two folders.
2

Build the Office Scripts

Office Scripts are TypeScript snippets that run against an Excel file. They do the same job map_row() and write_feeder() did in the Python script — you're pasting in code that already exists, not writing it from scratch.

1

Open the Automate tab

Open any Excel file from your SharePoint site in Excel Online (the blank template works fine). Click the Automate tab in the ribbon, then New Script.

2

Create "ReadSourceRows"

Delete the boilerplate function main(workbook: ExcelScript.Workbook) {…} that's there by default, and paste in the full script below. Rename the script (top-left, click the default name) to ReadSourceRows and save.

ReadSourceRows.ts
function main(workbook: ExcelScript.Workbook): string {
  const sheet = workbook.getWorksheets()[0];
  const usedRange = sheet.getUsedRange();

  if (!usedRange) {
    return JSON.stringify({ headers: [], rows: [] });
  }

  const values = usedRange.getValues();
  const headers = values[0].map((h) => String(h ?? "").trim());

  const rows = values
    .slice(1)
    .filter((row) => row.some((cell) => cell !== "" && cell !== null))
    .map((row) => {
      const obj: Record<string, string | number | boolean> = {};
      headers.forEach((h, i) => {
        obj[h] = row[i];
      });
      return obj;
    });

  return JSON.stringify({ headers, rows });
}
3

Test it

With your sample extract file open in Excel Online instead, run this script from the Automate tab (or point the script at it). It should return something like {"headers":["Rule Code","Trans Date",...],"rows":[...]}. If it returns empty, check that your data starts in row 1 of the first worksheet.

4

Create "PopulateFeederTemplate"

Same process — new script, paste the code below, name it PopulateFeederTemplate.

PopulateFeederTemplate.ts
const COA_VALUE = 2;

const UNUSED_FEEDER_COLUMNS = [
  "ACTIVITY", "LOCATION", "ENCDNUM", "ENCDITEMNUM",
  "ENCDSEQNUM", "ENCDACTIONIND", "ENCBTYPE",
];

interface MappingOptions {
  amountDivideBy100: boolean;
  ruleCodeStripPrefix: boolean;
}

type CellValue = string | number | boolean;
type SourceRow = Record<string, CellValue>;

function stripRuleCodePrefix(value: CellValue | undefined): CellValue | null {
  if (value === undefined || value === null || value === "") return null;
  const s = String(value).trim();
  const last3 = s.slice(-3);
  return /^\d+$/.test(last3) ? Number(last3) : last3;
}

function stripBankCodeSuffix(value: CellValue | undefined): CellValue | null {
  if (value === undefined || value === null || value === "") return null;
  let s = String(value).trim();
  if (s.endsWith("2")) s = s.slice(0, -1);
  return s === "" ? null : s;
}

function toAmount(value: CellValue | undefined, divideBy100: boolean): number | null {
  if (value === undefined || value === null || value === "") return null;
  const n = Number(value);
  if (Number.isNaN(n)) return null;
  const dollars = divideBy100 ? n / 100 : n;
  return Math.round(dollars * 100) / 100;
}

function mapRow(
  sourceRow: SourceRow,
  mapping: Record<string, string | null>,
  options: MappingOptions
): Record<string, CellValue | null> {
  const fromSource = (feederCol: string): CellValue | undefined => {
    const sourceHeader = mapping[feederCol];
    if (!sourceHeader) return undefined;
    return sourceRow[sourceHeader];
  };

  const result: Record<string, CellValue | null> = {
    RULECODE: options.ruleCodeStripPrefix
      ? stripRuleCodePrefix(fromSource("RULECODE"))
      : fromSource("RULECODE") ?? null,
    DOCREFERENCENUMBER: fromSource("DOCREFERENCENUMBER") ?? null,
    AMOUNT: toAmount(fromSource("AMOUNT"), options.amountDivideBy100),
    DESCRIPTION: fromSource("DESCRIPTION") ?? null,
    "SIGN (+/-)": fromSource("SIGN (+/-)") ?? null,
    BANKCODE: stripBankCodeSuffix(fromSource("BANKCODE")),
    COA: COA_VALUE,
    FUND: fromSource("FUND") ?? null,
    ORG: fromSource("ORG") ?? null,
    ACCOUNT: fromSource("ACCOUNT") ?? null,
    PROGRAM: fromSource("PROGRAM") ?? null,
  };

  for (const col of UNUSED_FEEDER_COLUMNS) {
    result[col] = null;
  }

  return result;
}

function main(
  workbook: ExcelScript.Workbook,
  sourceDataJson: string,
  columnMappingJson: string,
  optionsJson: string
): number {
  const { rows } = JSON.parse(sourceDataJson) as { headers: string[]; rows: SourceRow[] };
  const mapping = JSON.parse(columnMappingJson) as Record<string, string | null>;
  const options = JSON.parse(optionsJson) as MappingOptions;

  const sheet = workbook.getWorksheets()[0];
  const usedRange = sheet.getUsedRange();
  if (!usedRange) {
    throw new Error("Template sheet has no header row.");
  }

  const feederHeader = usedRange.getValues()[0].map((h) => String(h ?? "").trim());
  const feederRows = rows.map((r) => mapRow(r, mapping, options));

  const outputValues: CellValue[][] = feederRows.map((row) =>
    feederHeader.map((col) => {
      const v = row[col];
      return v === undefined || v === null ? "" : v;
    })
  );

  if (outputValues.length === 0) return 0;

  const startRow = usedRange.getRowCount();
  const targetRange = sheet.getRangeByIndexes(startRow, 0, outputValues.length, feederHeader.length);
  targetRange.setValues(outputValues);

  return outputValues.length;
}
Scripts are personal by default
A script you create is only runnable by you unless your tenant has the Office Scripts admin setting for sharing scripts turned on. For now, build and own the Power Automate flows under your own account — that's enough to get the app working end to end.

Create Flow B — "JVFeeder - Generate Feeder"

Same trigger type. Three inputs: SourceFile (File), ColumnMappingJson (Text), OptionsJson (Text).

6

Repeat the Create file + Run script (ReadSourceRows) steps

Identical to Flow A — this flow re-uploads the source file and re-reads it independently, so it doesn't depend on anything from Flow A having run first.

7

Add "Copy file" (SharePoint)

  • Source: /JV Feeder Files/Templates/JVFeederTemplate.xlsx
  • Destination: /JV Feeder Files/Outputs
  • New file name: concat('JVFeeder_output_', utcNow('yyyyMMdd_HHmmss'), '.xlsx')
  • If a file with this name already exists: Replace
8

Add a second "Run script"

File: the Id from Copy file. Script: PopulateFeederTemplate. Three parameters appear automatically once you pick the script — fill them with the Run script (step 6)'s result, and the flow's ColumnMappingJson / OptionsJson inputs.

9

Add "Get file properties" (SharePoint)

File Identifier: the Id from Copy file. This gives you a {Link to item} output — the file's real URL.

10

Add "Respond to a PowerApp or flow"

Three outputs: RowCount (Number, from the second Run script's result), OutputFileName (Text, the filename you built in step 7), DownloadUrl (Text, the Link to item from step 9).

Why not send the file straight back to Power Apps?
It's possible, but handling raw file bytes in Power Fx is finicky and version-dependent. Handing back a download link to a file that's already sitting in SharePoint is far more reliable, and it's what step 12 in Phase 4 uses.

The trickiest formula in this app
ParseJSON returns a dynamic value with no fixed shape, so Power Fx needs the explicit Table() / Text() wrapping above to turn it into a usable collection. If it errors, open the flow's outputs in the Power Apps monitor to see the exact JSON shape coming back, and adjust the wrapping to match.

Test End-to-End

Run through this checklist with a real sample file before sharing the app with anyone.

1

Happy path

Upload a file, map all 10 columns, leave both toggles off, generate, download, and open the result — confirm row count matches your source and values landed in the right columns.

2

Unmapped column

Leave one column unmapped and click Generate — confirm the row turns red and the button stays blocked with the warning message.

3

Legacy toggles

Turn on "Amount is in cents" with a cents-formatted source column and confirm the output divides by 100. Same for the rule-code prefix toggle.

4

COA reminder

Confirm every generated row shows COA = 2, and that Screen 3's note about correcting it for other charts is visible.

5

Share it

Share the app with a colleague who doesn't have a premium license and confirm they can open and run it — this is what confirms the standard-connectors-only approach actually held.
